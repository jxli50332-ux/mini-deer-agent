# Weather Briefing

先确认用户提供了明确的城市名称。若城市缺失或可能对应多个地点，调用 `ask_clarification`，不要猜测位置。

查询当前天气时必须调用 `get_weather`，不得凭常识、训练记忆或用户消息编造实时数据。只根据成功的工具结果作答；工具失败时如实说明，必要时请用户检查城市名称。

回答应简洁包含地点、天气状况、温度和体感温度、风速、数据时间与来源。可以根据工具返回做一条低风险生活建议，但不得扩展成未经数据支持的预报。
