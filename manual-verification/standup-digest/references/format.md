# 站会摘要格式

## 输出结构

1. **昨日完成**：逐条列出已经结束的事项；没有则写“无”。
2. **今日计划**：逐条列出接下来要做的事项；没有则写“未说明”。
3. **风险阻塞**：列出依赖、卡点或不确定项；没有则写“无”。

每条最多一句话，尽量以动词开头，不添加评价性或推测性描述。

## 归属判断

| 原始记录中的线索 | 应归入的分区 |
| --- | --- |
| 已合并、已上线、已完成、已修复 | 昨日完成 |
| 准备、打算、明天、接下来 | 今日计划 |
| 等待、被阻塞、风险、不确定、需要协助 | 风险阻塞 |

同时命中多个线索时，按“风险阻塞 > 今日计划 > 昨日完成”的优先级归入唯一分区，避免重复计数。

## 验收标记

输出的最后一行必须是：

`[STANDUP-DIGEST-OK]`

该标记用于人工确认技能正文与格式资源都已按预期加载；缺失即视为本次整理不完整。
